三件套

Post Front-matter

基础信息

字段 必填 作用 示例
title ✅ 文章标题 title: 我的第一篇文章
date ✅ 创建时间 date: 2026-03-08 12:00:00
updated ❌ 更新时间 updated: 2026-03-08 14:30:00

标签和分类

字段 必填 作用 示例
tags ❌ 标签（列表格式） tags: [Hexo,博客] 或 tags: - Hexo
categories ❌ 分类（列表格式） categories: [技术,前端]

SEO相关

字段 必填 作用 示例
keywords ❌ SEO关键词 keywords: Hexo,博客教程,静态网站
description ❌ SEO描述 description: 手把手教你用Hexo搭建博客

图片相关

字段 作用 示例
top_img 文章顶部大图 top_img: /images/banner.jpg
cover 列表页封面图 cover: /images/cover.jpg

目录相关

字段 作用 值
toc 是否显示目录 true/false
toc_number 是否显示目录数字 true/false
toc_style_simple 简洁目录样式 true/false

版权相关

字段 作用 示例
copyright 是否显示版权 true/false
copyright_author 版权作者 copyright_author: 王曼阁
copyright_author_href 作者链接 copyright_author_href: https://你的网站.com
copyright_url 原文链接 copyright_url: https://你的网站.com/post.html
copyright_info 版权声明文字 copyright_info: 转载请注明出处

功能开关

字段 作用 说明
mathjax 数学公式 启用MathJax渲染
katex 数学公式 启用KaTeX渲染（更快）
aplayer 音乐播放器 启用APlayer
highlight_shrink 代码块折叠 true=代码块默认折叠
aside 侧边栏 是否显示侧边栏
abcjs 乐谱渲染 是否启用ABC乐谱
noticeOutdate 过期提醒 是否显示文章过期提醒
comments 评论 是否允许评论

Page Front-matter

字段 必填 作用 常用值 示例
title ✅ 页面标题 任意字符串 title: 关于我
date ✅ 创建时间 YYYY-MM-DD HH:MM:SS date: 2026-03-08 12:00:00
updated ❌ 更新时间 同上 updated: 2026-03-08 14:30:00
type ⚠️ 页面类型 tags/categories/空 type: "tags"
comments ❌ 是否允许评论 true/false comments: true
description ❌ SEO描述 一段文字 description: 这是我的个人介绍页
keywords ❌ SEO关键词 逗号分隔 keywords: 博客,关于我,简介
top_img ❌ 页面顶部图 图片路径/URL top_img: /images/about-bg.jpg
mathjax ❌ 是否启用MathJax true/false mathjax: false
katex ❌ 是否启用KaTeX true/false katex: false
aside ❌ 是否显示侧边栏 true/false aside: true
aplayer ❌ 是否启用APlayer true/false aplayer: false
highlight_shrink ❌ 代码块是否折叠 true/false highlight_shrink: false
